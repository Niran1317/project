Misinformation Influence Minimization

Educational interface for the graph-based project.

Project Workflow

  1. Represent users as nodes in a social graph.
  2. Represent relationships as edges.
  3. Rank candidate nodes by their current influence/degree.
  4. Greedily block selected high-impact nodes.
  5. Use a Bloom filter for fast keyword-based spam screening.
