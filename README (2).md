# Model files

This project expects the following OpenCV DNN model files in this folder:

- `opencv_face_detector.pbtxt`
- `opencv_face_detector_uint8.pb`
- `age_deploy.prototxt`
- `age_net.caffemodel`
- `gender_deploy.prototxt`
- `gender_net.caffemodel`

These are pretrained OpenCV DNN model files. Do not commit large model files if your GitHub repository size becomes an issue; download them locally before running.
